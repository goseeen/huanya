## 重现安装包

```sh
zsh scripts/test.sh
zsh scripts/package.sh
```

输出至 `dist/releases/1.0.0/`。同名包已存在时脚本停止，不覆盖历史安装包。Release 使用与构建源码一致的提交创建 `v1.0.0` 标签，附上两个 DMG 和同目录的 `SHA256SUMS.txt`。发布说明见 [1.0.0.md](releases/1.0.0.md)。
