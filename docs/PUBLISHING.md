## 制作安装包

仅在准备发布安装包时执行。不能将旧内部版本安装包改名当作 1.0.2，需要从当前源码重新构建。

```sh
zsh scripts/test.sh
zsh scripts/package.sh
```

输出至 `dist/releases/1.0.2/`，与旧本地内部包的 `dist/installers/` 分开。同名文件已存在时脚本停止。

Release 标签建议 `v1.0.2`，说明见 `docs/releases/1.0.2.md`。核对后上传两个 DMG 和同目录的 `SHA256SUMS.txt`，不要上传 .build、数据备份或整个开发目录。

当前版本号为 1.0.2，内部构建号为 9，包含自定义休息时长与图表悬浮提示，区别此前本地开发构建。应用标识和数据路径保持一致。尚无 Developer ID 签名与公证，发布说明应如实说明。Apple 芯片实机未验证时保留说明。

首发不设置收款码，不创建赞助配置。
