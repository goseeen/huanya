# 1.0.1 发布准备

当前先保持 Private，私人仓库上传不代表已完成公开发布。

本发布仓库从当前源码快照建立新历史；提交使用 GitHub noreply 邮箱。素材制作依据、MIT 范围及系统资源边界已记录，公开前仍需完成下面的核查与确认。

## 公开前

- [x] 记录 ASSETS.md 中项目自制图形的制作依据，明确 MIT 范围与系统资源边界。
- [x] 补充 README 使用须知、DISCLAIMER.md 与贡献来源要求，保留标准 MIT 许可原文。
- [ ] 完成 ASSETS.md 中标识相似性及名称、商标的核查，记录范围和结果。
- [ ] 检查所有文件与提交历史，不含个人统计、CSV、备份、证书或凭据。
- [ ] 检查提交身份，不使用工作邮箱或其他不希望公开的身份信息。
- [ ] 确认 README、MIT 许可、素材说明、免责声明、问题模板相互一致且完整。
- [ ] 通过测试与两个架构构建，明确尚未完成的实机验证。
- [ ] 最后确认将仓库改为 Public。

## 制作安装包

仅在准备发布安装包时执行。不能将旧内部版本安装包改名当作 1.0.1，需要从当前源码重新构建。

```sh
zsh scripts/test.sh
zsh scripts/package.sh
```

输出至 `dist/releases/1.0.1/`，与旧本地内部包的 `dist/installers/` 分开。同名文件已存在时脚本停止。

Release 标签建议 `v1.0.1`，说明见 `docs/releases/1.0.1.md`。核对后上传两个 DMG 和同目录的 `SHA256SUMS.txt`，不要上传 .build、数据备份或整个开发目录。

当前版本号为 1.0.1，内部构建号为 8，包含自定义休息时长与图表悬浮提示，区别此前本地开发构建。应用标识和数据路径保持一致。尚无 Developer ID 签名与公证，发布说明应如实说明。Apple 芯片实机未验证时保留说明。

首发不设置收款码，不创建赞助配置。
