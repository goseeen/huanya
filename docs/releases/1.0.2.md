# 缓芽 · huǎn yá 1.0.2

本版将应用从“起身 RiseUp”更名为“缓芽”，展示拼音为 **huǎn yá**，安装包文件名使用 **huanya**。

- 主界面、菜单栏、通知、关于页面、辅助功能标签和 CSV 导出名称保持一致。
- 保留原有抬手小人图标，以及喝水、护眼、拉伸、自定义休息时长和图表悬浮提示等功能。
- 应用标识与数据目录保持兼容，已有设置及统计无需迁移。

更名前的应用也会读取同一个数据文件。后续安装时请先退出旧版本，用“缓芽.app”替换“起身 RiseUp.app”，不要同时运行两个副本。备份方式见 [README](../../README.md#本地数据备份与隐私)。

要求 macOS 13 或更新版本，构建号为 9。本文件为发布草稿；Intel 安装包已制作并在开发机安装到“应用程序”验证，GitHub Release 尚未发布。当前构建使用本地临时签名，尚无 Apple Developer ID 签名与公证。本版 Apple 芯片安装包尚未制作，实机验证仍待完成。

本地验证：307 项核心及集成断言通过，Intel 编译和临时签名校验通过；演示模式的界面截图、菜单栏、快捷键、自动浮窗及实际休息倒计时检查通过。截图使用演示数据。

Intel 安装包已通过只读挂载、架构、签名、应用内容和 SHA-256 校验。更名安装后已启动，既有设置、历史每日统计和明细记录保留；旧应用和数据已在本地备份。

名称确定不代表商标核查完成。名称、素材与公开状态见 [命名记录](../NAMING.md)、[素材说明](../../ASSETS.md) 和 [发布准备](../PUBLISHING.md)。
