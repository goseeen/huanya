# 起身 RiseUp 1.0.1

工作很重要，你也是。

本版包含完整的喝水、护眼和起身拉伸提醒，并增加两项日常使用改进：

- **休息时长由你决定**：在提醒计划中选择“自定义”，输入分钟和秒，例如 3 分钟。护眼与拉伸分别保存，支持 10 秒至 10 分钟，保留原有常用选项。
- **看清每个小时的工作量**：鼠标悬停在图表的任意小时区域，即可查看时间范围和累计工作分钟数。整列高亮，零记录与未来时段分别提示，提示卡在图表两端自动避让。

其他功能包括独立提醒计划、工作时段与周末规则、空闲与锁屏暂停、合并提醒与提前预告、快捷杯量与撤销、忙碌模式、动作图卡、本地统计与 CSV 导出。

要求 macOS 13 或更新版本。按芯片选择 Intel 或 AppleSilicon 安装包；更新前退出旧应用，正常替换保留设置与记录。统计只保存在本机。

构建号为 8。Intel 构建已通过测试和本机运行验证；本次 Apple 芯片安装包尚待构建与实机验证。应用尚未经过 Apple Developer ID 签名或公证。
