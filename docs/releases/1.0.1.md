# 缓芽 · huǎn yá 1.0.1

工作很重要，你也是。

本次修复两处提醒体验，让暂停和开始休息更连贯。

## 修复

- **切换应用后，继续剩余时间。** 指定的暂停应用处于前台时，提醒倒计时暂停；切换离开后从剩余时间继续。例如还剩 10 分钟时暂停，回来仍从 10 分钟继续。在多个指定应用之间切换时保持暂停。这适用于所有配置的应用。
- **预告中点“现在休息”，直接开始。** 点击后打开正式浮窗并进入护眼或拉伸倒计时，无需再点一次“开始休息”。浮窗预告和系统通知操作一致。组合提醒一次只开始一项休息，喝水仍需确认；倒计时结束后仍需确认才记录完成。

手动暂停、忙碌模式、空闲、锁屏及睡眠仍按各自规则处理；本次未增加会议状态检测。

## 下载与更新

要求 **macOS 13 或更新版本**，按电脑芯片选一个安装包：

| 电脑 | 安装包 |
| --- | --- |
| Intel Mac | [huanya-1.0.1-Intel-x86_64.dmg](https://github.com/goseeen/huanya/releases/download/v1.0.1/huanya-1.0.1-Intel-x86_64.dmg) |
| M 系列 Apple 芯片 Mac | [huanya-1.0.1-AppleSilicon-arm64.dmg](https://github.com/goseeen/huanya/releases/download/v1.0.1/huanya-1.0.1-AppleSilicon-arm64.dmg) |
| 文件完整性校验 | [SHA256SUMS.txt](https://github.com/goseeen/huanya/releases/download/v1.0.1/SHA256SUMS.txt) |

先退出正在运行的缓芽，打开 DMG，将“缓芽.app”拖入 Applications 并替换旧应用。弹出映像后从“应用程序”启动，不要同时运行多个版本。

应用标识与数据目录保持兼容，正常替换应用会保留设置与统计。备份时先退出应用，再复制 `~/Library/Application Support/RiseUp/state.json`；请勿清理该目录。
