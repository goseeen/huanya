# 起身 RiseUp 1.0.0

工作很重要，你也是。

首次公开版本包含喝水、护眼、起身拉伸提醒，支持 Intel 与 M 系列 Apple 芯片，要求 macOS 13 或更新版本。

- 独立提醒计划、工作时段、周末规则，浮窗或系统通知。
- 空闲与锁屏暂停、前台应用暂停、忙碌模式、合并与预告。
- 快捷杯量、饮水撤销、休息倒计时，自动与手动切换动作。
- 本地统计、7 天趋势、工作时段分布与 CSV 导出。
- 可选登录时启动、菜单栏倒计时与全局快捷键。

按芯片选择 Intel 或 AppleSilicon 安装包。安装前退出已有应用，拖入 Applications 后从“应用程序”启动。正常替换应用保留设置与记录。

应用使用本地临时签名，尚无 Apple Developer ID 签名与公证。首次启动可能需按系统“隐私与安全性”提示允许。随包的 SHA256SUMS.txt 用于核对完整性。

Apple 芯片构建尚待实机验证，发布前应更新状态。本轮使用时长为估算，不识别实际坐姿。节假日与日历尚未接入。

本文件为草稿，安装包与 Release 尚未发布。
